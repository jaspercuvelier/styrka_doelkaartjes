# Doelkaartjes OV1-2 (Styrka)

Statische website, gebouwd met `maak_site.py` in de map erboven. Niet met de hand aanpassen.

- `kaartjes/` : doelkaartjes maken per leerling (PDF), leerlingen worden in de browser bewaard
- `nakijken/` : prenten nakijken (feedback wordt als bestand gedownload en gemaild)
- `rapport/` : rapport maken uit doelenfiche + handelingsplan + eindrapport (apart project, bron in de map rapport)
- `img/`, `assets/` : prenten en logo's

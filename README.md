# Doelkaartjes OV1-2 (Styrka)

Statische website, gebouwd met `maak_site.py` uit de map OV1-2. Niet met de hand aanpassen.

- `kaartjes/` : doelkaartjes maken per leerling (PDF), leerlingen worden in de browser bewaard
- `nakijken/` : prenten nakijken (feedback versturen werkt enkel op Netlify; elders: feedback downloaden)
- `img/`, `assets/` : prenten en logo's
